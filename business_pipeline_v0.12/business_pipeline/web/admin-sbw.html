Generate the writer's own paper for a tile from its prefilled instruction. Every subject is a section; tile groups are collapsible; ticks survive a subsection switch. A corpus source is cited only when a page matches; an empty result is a named gap.

Tile cases

Each case is one tile's instruction, declared figures and the frozen method's result. A failure is logged as a tile-case error with its case id; the loop re-checks it by code with no model call. A pass is a stored regression test.
