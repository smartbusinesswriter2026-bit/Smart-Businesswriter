# Sample papers: how they were made

The `samples/` folder holds worked examples. The four papers added with B-152 are **generated by the
conductor and the academic formatter** — not typed by hand — so they show what the product actually
produces.

| File | Framework | Evidence |
|---|---|---|
| `Apple's Entry into Iran - Ansoff - APA 7.docx` | Ansoff Growth Matrix | frozen sources (below) |
| `Apple's Entry into Iran - Ansoff - Harvard.docx` | Ansoff Growth Matrix | frozen sources |
| `Apple's Entry into Iran - Value Chain - APA 7.docx` | Value Chain | frozen sources, one named gap |
| `Apple's Entry into Iran - Value Chain - Harvard.docx` | Value Chain | frozen sources, one named gap |
| `Apple's Resource Position - VRIO - APA 7.docx` | VRIO | none by design (student judgments) |
| `Apple's Resource Position - VRIO - Harvard.docx` | VRIO | none by design |
| `A Tehran Device Store - Break-even - APA 7.docx` | Break-even | none; frozen core from declared figures |
| `A Tehran Device Store - Break-even - Harvard.docx` | Break-even | none |

## How to rebuild them

```powershell
Set-Location "D:\SMART BUSINESSWRITER\business_pipeline_v0.12\business_pipeline"
$env:PYTHONPATH="src"
python scripts\build_conductor_samples.py
```

The script runs `chat.start`, answers the question bank, confirms the plan, drafts and calls
`chat.docx_bytes`, which enforces the export gate and renders `bp.product.docx.render_academic`. If the
conductor or the formatter changes, rebuilding the samples shows the change — they cannot silently drift.

## The Home-page bundle: one framework and one computation

`samples/pestel-and-break-even-tehran-device-store-submission.zip` is the worked example the Home page
lists under **Documents**. It is one PESTEL paper with one break-even computation, exported exactly as a
student's export is: a ZIP holding the paper and its computation explainer.

- the paper carries the six PESTEL dimensions with a frozen source in each, one recorded break-even
  (fixed 2,000,000; price 40,000; variable 28,000) and a declared-inputs line the gate checks;
- the explainer is `explain.paper_document` over the same recorded case: the question, why the method,
  the declared formula, the figures, the result, the limits and the likely questions.

Rebuild it with:

```powershell
Set-Location "D:\SMART BUSINESSWRITER\business_pipeline_v0.12\business_pipeline"
$env:PYTHONPATH="src;scripts"
python scripts\build_home_sample.py
```

The script runs `chat.start`, the question bank, `confirm_plan`, the break-even capability, the evidence
seeding and `chat.draft`, then `chat.docx_bytes` and `explain.paper_document`; nothing is typed by hand,
so the sample cannot drift from the product.

## Where the evidence comes from

`scripts/sample_evidence.py` holds nine records already cited in this repository's Apple-Iran paper
(World Bank, Koruzhde, Thomas, Conduit, Bashirov et al., Haji & Fallah Haghighi, Ahmadi et al., Pesaran &
Smith). Each record carries the one-sentence claim the existing sample makes from it. The file also states
which source supports which dimension; that placement is an editorial choice for the worked example, not a
retrieval result.

No source is invented, and nothing is newly retrieved. A live paper places sources through the conductor's
own ranking and will show gaps where the sources are thin.

## What the samples show honestly

- **VRIO and Break-even** say in the introduction that no external evidence is retrieved; their reference
  list reads "No sources were used."
- **Value Chain** leaves `Service` as a named gap: no frozen source describes a service activity for a firm
  that does not operate in the market.
- **Break-even** reports the core's figures as they are, including a negative margin of safety when the
  declared volume is below break-even.
- The title page carries a byline ("Smart Business Writer / Worked example for students"), never
  `[your name]`.

## What is not in these samples

- No student name, course code or institution (the byline is optional and the product does not invent one).
- No prose written by a model.
- No weighting, scoring or recommendation: the Discussion and Implications state what the evidence supports
  and what it does not.
