# Stage 5 handoff package

This package is for Claude or another coding model working on **Build Charter Stage 5: Quantitative Method and Verification Library**.

## Files and authority

1. `business_pipeline_v0.3.docx` — a copy of the supplied source manual, unchanged in content. It is the authoritative source manual.
2. `business_pipeline_v0.3.md` — a convenience Markdown rendering of the supplied manual. If formatting or interpretation differs, defer to the DOCX.
3. `Initial_Build_Charter_Unified_Adaptive_Workbench_v0.1.md` — the staged, amendable overall build instructions.
4. `Stage_5_Quantitative_Method_and_Verification_Library_Build_Brief_v0.1.docx` and `.md` — stage-specific instructions derived from the manual and Build Charter.
5. `Business_Frameworks_and_Quantitative_Methods_Catalogue_v0.2.md` — the current curated candidate catalogue, including the framework/model/quantitative-method distinction.

## Start instruction

Read the Build Charter, the v0.3 manual, and the Stage 5 brief. Then inspect the codebase and current Stage 0–4 work before changing anything. Do not assume implementation status from these documents. Run baseline tests and report results accurately.

Stage 5 is not a request to implement every quantitative method. It begins with an audit, then the smallest valuable end-to-end method increment, with input contracts, assumptions, tests, verification, artifacts, provenance, and accurate tier/status labels.
