Data ingestion (structured files)

Read a CSV/TSV or XLSX file into a typed table with a provenance pointer. PDF, scans and SPSS files are refused by this route: no PDF text extraction or OCR happens here. A case document is read for its text on the Documents tab, where a scanned page needs an OCR engine on this machine and then carries the label unverified_ocr_text. The file belongs to a case: open one and the data is attached to it, and its columns can become the inputs of a run.

Assistant & help

What this is

A local workbench that calls the local API. Every number shown is computed by the method library and printed exactly as the server returned it. Nothing is calculated in the browser.

How to work

1. Name the case and open it. The case holds the case study, the spreadsheet, the argument and every run.
2. Attach the case study to the case, and add the spreadsheet under Data.
3. Use the columns of the spreadsheet as the inputs of a run, then read the result and its honesty notes.
4. Keep the facts and alternatives you agree with; the assistant proposes, you decide.
5. Charts are drawn by the server from the values that were recorded.

Offline

No external network calls, no web fonts, no analytics. Model assistance is off unless the server was started with a provider configured.
