Hybrid Reasoning Agents (arXiv:2610.18861v1, 13 Oct 2026) → this pipeline
Honest status: designed, not built. The paper informed the architecture in this mockup and the sequencing in the plan. No pipeline code has been changed — the existing spine is untouched, the Anthropic adapter has never been run live, and no latent mode exists at runtime. Every integration below is a proposal with a defined seam, not an implemented feature.
The central finding. The pipeline is already a text-mode hybrid agent: it draws the line between external, auditable, user-visible output and internal deliberation, and the deterministic spine is the part that never needs a model. What the paper contributes is a mode policy (when to think vs. when to act) and a post-training recipe — not new plumbing. And the pipeline already satisfies the paper's key enabler: hybrid policy factorization holds here by construction, because the model's stochasticity is confined to proposals it cannot verify.

The one place the paper and the manual disagree — and the resolution

Paper: the model learns when to enter and exit latent mode. Manual (P4): code decides the order of stages and whether verification runs; agents are subroutines whose output always passes a check they do not control.

Resolution — the line is mode, not verification. Choosing how much to verbalise is not the same as choosing whether a check runs. A learned mode policy may change the length and timing of a proposal, but the frozen test plan, the thresholds, the stage order and the pass/fail decision all stay in code. Mode switching cannot alter the verification outcome — so P4 holds.

The test that enforces it: the same run, executed with the learned mode policy and with latent mode disabled entirely, must produce identical artifacts, identical check results and an identical report. Only latency, token count and proposal quality may differ. That single property is the gate for the entire hybrid path, and it is exactly the kind of metamorphic test the manual's evaluation plan already calls for.
